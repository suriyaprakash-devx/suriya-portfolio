## 🛠️ Tech Stack

- **Markup & Styling**: HTML5, CSS3 (Custom Variables, Flexbox, CSS Grid)
- **Typography**: Space Grotesk, Inter, JetBrains Mono (Google Fonts)
- **Scripting**: Vanilla JavaScript (ES6+), Canvas API, IntersectionObserver API

## 🌐 Live Preview / Deployment

You can enable **GitHub Pages** to host this portfolio for free:
1. Go to **Settings** > **Pages** in this repository.
2. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Click **Save**. Your site will be published at `https://suriyaprakash-devx.github.io/suriya-portfolio/`.
